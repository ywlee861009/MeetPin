# Pin 프로필 이미지 적용 (pin-profile-image)

## 🎯 목적과 배경
현재 실시간 트래킹 화면(`LiveTrackingScreen`)의 유저 마커(Pin)는 닉네임 첫 글자(이니셜)만 표시하고 있습니다. 이를 실제 유저의 프로필 사진으로 교체하여 지도 상에서 유저를 더 쉽고 직관적으로 식별할 수 있도록 합니다.

## 📝 하위 티켓 목록
- `phase1_data-model.md`: Participant 데이터 모델에 프로필 이미지 URL 추가 및 연동
- `phase2_marker-ui.md`: AvatarMarker UI를 Coil AsyncImage로 교체 및 디자인 개선

## 🔄 선행 관계
- phase1 ➔ phase2 순으로 진행

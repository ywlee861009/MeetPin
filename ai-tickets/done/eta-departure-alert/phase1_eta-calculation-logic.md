# Phase 1: 도착 예정 시간(ETA) 계산 로직

## 🎯 목표
- 현재 좌표에서 약속 장소까지의 이동 시간을 정확도 높게(또는 Mock으로) 계산하는 로직을 작성합니다.

## 🛠️ 수정 대상
- `ArrivalDetector.kt` 또는 신규 `EtaCalculator.kt` (`core/location/`)

## 📝 구체적인 구현 방향
- 두 좌표 간의 거리 및 이동 수단(도보/대중교통)을 기반으로 예상 소요 분(Minutes)을 반환하는 함수 작성
- 현재는 외부 라우팅 API(Directions API) 연결 전이므로, 직선거리 기반 이동 속도 모델을 고도화하여 Mock 데이터로 사용

## 🔍 검증 방법

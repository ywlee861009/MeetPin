# Phase 3: 마커 페널티 UI 표시

## 🎯 목표
- 계산된 지각 시간과 벌금을 맵 화면의 참가자 핀(마커) 위에 눈에 띄게(강렬한 색상으로) 표시합니다.

## 🛠️ 수정 대상
- `LiveTrackingScreen.kt` (`AnimatedParticipantMarker`)

## 📝 구체적인 구현 방향
- `ParticipantMarker`의 `lateMinutes`가 0보다 클 경우, 마커 컴포저블 내에 지각 상태 뱃지를 렌더링
- 예: 빨간색 배경의 텍스트 박스로 "지각 +3분 (3,000원)" 표시
- 애니메이션 효과(Blinking 또는 팝업)를 넣어 지각자임을 강조

## 🔍 검증 방법
- 지각한 유저의 마커 위에 페널티 정보가 제대로 나타나는지 확인
- 벌금 및 시간이 증가할 때 UI가 자연스럽게 업데이트 되는지 확인

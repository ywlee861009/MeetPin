# Phase 1: 약속 시간 및 벌칙금 데이터 모델 추가

## 🎯 목표
- 약속 그룹(Group) 데이터에 '약속 시간'과 '지각비 규칙'을 설정할 수 있도록 모델을 확장합니다.

## 🛠️ 수정 대상
- `Group` 및 `Participant` 관련 데이터 모델 (`core/model/`)

## 📝 구체적인 구현 방향
- `Group` 클래스에 `appointmentTime: Long` (약속 시간 Timestamp) 추가
- `Group` 또는 별도 설정 클래스에 `penaltyPerMinute: Int` (예: 1분당 1000원) 필드 추가
- 기존 Mock 데이터 생성 로직에 약속 시간(현재 시간 기준 1분 전 등 테스트용) 및 벌칙금 세팅 반영

## 🔍 검증 방법
- 앱 빌드 후 데이터 모델 구조에 에러가 없는지 확인
- Mock 데이터가 정상적으로 인스턴스화 되는지 확인

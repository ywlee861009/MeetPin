# Phase 3: 기타 화면 반응형 레이아웃 대응

## 🎯 목표
- 약속 생성 화면 및 대기실(Lobby) 화면도 태블릿 환경에 맞게 최적화합니다.

## 🛠️ 수정 대상
- `CreatePinScreen.kt`
- `LobbyScreen.kt`

## 📝 구체적인 구현 방향
- 폼(Form) 요소가 많은 화면은 `Expanded` 상태에서 양옆 여백을 주어 입력 필드가 너무 길어지지 않게 최대 너비(`widthIn`)를 제한합니다.
- 대기실의 경우 참가자 리스트를 그리드(`LazyVerticalGrid`) 형태로 보여주어 가로 공간을 넓게 활용합니다.

## 🔍 검증 방법
- 태블릿에서 약속 생성 화면과 대기실 화면에 진입했을 때 UI가 어색하게 늘어나지 않고 보기 편한지 확인

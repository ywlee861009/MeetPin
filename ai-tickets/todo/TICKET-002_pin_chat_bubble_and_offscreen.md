# [TICKET-002] 맵 핀 말풍선 팝업 및 화면 밖 유저 방향 표시 기능

## 🎯 목표
- 유저가 채팅을 입력했을 때, 맵 상의 해당 유저 핀에 말풍선이 나타났다 사라지는 애니메이션을 구현합니다.
- 해당 유저가 현재 화면 카메라 밖(Off-screen)에 위치할 경우, 유저가 있는 방향의 화면 가장자리에 말풍선을 표시하여 채팅을 알 수 있게 합니다.

## 📝 세부 작업 목록
- [ ] 채팅 입력을 위한 하단 채팅바 또는 플로팅 버튼(TextField 포함) UI 구현
- [ ] `ParticipantMarker` 상태 모델에 일시적인 `chatMessage` 상태 및 표시 여부 필드 추가
- [ ] `LiveTrackingScreen.kt` 내 유저 핀(`MarkerComposable`) 위에 팝업되는 말풍선 UI 및 사라지는 타이머(애니메이션) 구현
- [ ] GoogleMap 카메라의 `Projection`을 활용하여 화면 밖 유저의 화면 가장자리 좌표를 계산하는 로직 구현
- [ ] 화면 밖 유저가 채팅 시, 가장자리 좌표에 말풍선을 렌더링하고 유저가 있는 방향을 가리키는 UI 추가

## 🔍 검증 기준
- [ ] 채팅 입력 시 맵 내 유저 핀 위에 말풍선이 애니메이션과 함께 나타나고 몇 초 뒤 자연스럽게 사라지는가?
- [ ] 화면 밖에 있는 유저가 채팅 시, 화면 모서리(해당 유저 방향)에 말풍선이 올바르게 나타나는가?
- [ ] 방향을 가리키는 각도 및 말풍선 UI가 자연스럽고 보기 좋은가?
- [ ] 빌드 성공 및 맵 줌/패닝 시 말풍선 위치 업데이트가 정상적으로 작동하는가?

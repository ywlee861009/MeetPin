# 맵 핀 말풍선 팝업 및 화면 밖 유저 방향 표시 (pin-chat-bubble)

## 🎯 목적과 배경
모임 참여자들이 목적지로 모이는 동안 서로 상호작용할 수 있도록 맵 위에 채팅 기능을 도입합니다.
일반적인 채팅창 대신 맵 핀 위에 말풍선을 띄우고, 유저가 화면 밖에 있으면 가장자리에 방향을 알려주는 직관적이고 귀여운 UI를 목표로 합니다.

## 📝 하위 티켓 목록
- `phase1_chat-state-ui.md`: 채팅 입력 UI 및 상태 모델(ViewModel) 구현
- `phase2_map-marker-bubble.md`: 맵 상의 핀 위에 팝업되는 말풍선 UI 애니메이션 구현
- `phase3_offscreen-indicator.md`: 화면 밖 유저 채팅 시 모서리 방향 표시(Off-screen Indicator) 구현

## 🔄 선행 관계
- phase1 ➔ phase2 ➔ phase3 순으로 진행

# Phase 3: 화면 밖 유저 방향 표시(Off-screen Indicator)

## 🎯 목표
- 채팅을 친 유저가 현재 카메라 화면 밖에 있을 때, 유저가 있는 방향의 화면 가장자리에 말풍선을 띄워줍니다.

## 🛠️ 수정 대상
- `LiveTrackingScreen.kt` (카메라 Projection 및 오버레이 계산 로직)

## 📝 구체적인 구현 방향
- Google Map의 `Projection.toScreenLocation()`을 활용하여 마커의 화면 좌표를 구합니다.
- 화면 크기 경계를 벗어난 좌표일 경우, 화면 가장자리(테두리)와 교차하는 점을 삼각함수(기하학)를 사용해 계산합니다.
- 이 계산된 위치(가장자리)에 말풍선을 `Box` 오버레이 형태로 띄우고 방향 화살표를 회전시켜 표시합니다.

## 🔍 검증 방법
- 화면 밖의 유저가 채팅 시, 정확한 방향의 화면 모서리에 말풍선이 나타나는지 확인
- 화면을 스와이프하여 유저가 화면 안으로 들어오면 모서리 말풍선이 사라지고 마커 위 말풍선으로 자연스럽게 전환되는지 확인

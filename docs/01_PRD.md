# 📄 01. PRD (Product Requirement Document) - MeetPin

> **⚠️ 구현 현황 — 「단일 기기 데모 / 백엔드 미구현」 단계 (2026-08-01 기준)**
> 이 문서는 목표 스펙입니다. 현재 코드는 백엔드·실시간 서버가 없어(`:core:network` 비어 있음, 인메모리 `FakeMeetPinRepository`만 존재) **기기 간 실시간 위치 공유는 동작하지 않으며**, 친구 위치·이동·도착은 단일 기기 내 데모 시뮬레이션입니다. 아키텍처·UI·화면 플로우는 데모로 동작합니다.

## 1. 개요 (Overview)
- **제품명**: MeetPin (밋핀)
- **플랫폼**: Android (Android 8.0 Oreo / API 26 이상 권장)
- **한 줄 요약**: Google 지도 기반의 모임 장소 핀 설정 및 **전원 승낙 방식**의 실시간 위치 공유 약속 앱.
- **핵심 목표**: 약속 시 반복되는 "지금 어디야?", "다 왔어?" 식의 번거로운 소통을 줄이고, 친구들 모두가 동의했을 때만 약속 장소에 모일 때까지 안심하고 위치를 공유하는 경험을 제공합니다.

---

## 2. 해결하고자 하는 문제 (Problem Statement)
1. **약속 장소 이동 중 소통의 번거로움**: 약속 시간에 임박했을 때 각 참가자의 위치와 도착 시간을 매번 텍스트나 전화로 확인해야 함.
2. **무분별한 위치 공유에 대한 사생활 부담**: 기존 위치 공유 앱들은 24시간 계속 공유되거나 언제 꺼지는지 불투명하여 사생활 침해 우려가 큼.
3. **상호 동의 부재**: 한 사람이라도 수락하지 않은 상태에서 동의 없이 한쪽 위치만 노출되는 불균형 문제.

---

## 3. 핵심 비전 & 동작 원리 (Core Concept & Mechanics)

```
[주선자: 핀 찍기 및 약속 생성]
            │
            ▼
[친구들에게 딥링크 초대장 발송]
            │
            ▼
[친구들의 초대 수락 (대기실)]
            │
   ┌────────┴────────┐
   ▼                 ▼
[일부 미승낙]       [모든 초대 인원 승낙 완료!]
 (공유 대기 중)             │
                            ▼
               [🚀 실시간 위치 공유 모드 자동 ON]
                            │
                            ▼
               [📍 약속 장소 반경 도착 또는 모임 완료]
                            │
                            ▼
               [🔒 위치 공유 자동 종료 (사생활 보호)]
```

## 4. 주요 기능 명세 (Key Features)

### 4.1 약속(Pin) 생성 및 장소 지정 (Host)
- **Google Maps 기반 검색 & 핀 클릭**:
  - 장소명/주소 검색 또는 지도 직접 터치를 통한 핀(Pin) 생성.
  - 약속 명칭(예: "홍대 입구 9번 출구 앞"), 약속 시간 설정.
- **초대 인원 설정 & 딥링크 생성**:
  - 약속 생성 즉시 고유 딥링크(App Link) 생성 (카카오톡, SMS, 라인 등 공유 가능).

### 4.2 초대 승낙 & 대기실 (Invitation & Lobby)
- **딥링크 접속 및 참여 결정**:
  - 앱 미설치 시 플레이스토어로 연결, 앱 설치 시 초대 수락 팝업 띄움.
- **전원 승낙 조건부 트리거**:
  - 대기실에서 "승낙(Accept)", "거절(Decline)" 상태 표출.
  - **참가 대상 전원이 승낙 버튼을 누르는 순간** `Group Status`가 `ACTIVE`로 변경되며 실시간 위치 공유 서비스 가동.

### 4.3 실시간 위치 공유 및 라이브 지도 (Live Tracking)
- **실시간 참가자 마커(Marker)**:
  - 구글 지도 상에 각 참가자의 아바타/프로필 아이콘 마커 표시.
  - 참가자별 이동 속도, 거리, 예상 소요시간(ETA) 표시.
- **백그라운드 위치 추적 (Foreground Service)**:
  - 앱을 이탈하거나 화면을 꺼도 상단 알림창(Notification) 표시와 함께 위치 수집 유지.
- **도착 감지 (Geofencing)**:
  - 약속 장소 반경(예: 50m) 진입 시 "도착 완료" 핑 및 알람 수신.
  - 모든 멤버 도착 시 또는 주선자가 약속 종료 클릭 시 실시간 공유 자동 파기.

## 5. 추후 확장 기능 아이디어 (Future Enhancements)

1. **⚖️ 중간 지점 자동 추천 (Pin Center)**:
   - 친구들의 출발 위치를 분석하여 가장 합리적인 중간 모임 장소/지하철역 추천.
2. **🏃 ETA 비교 및 출발 알림**:
   - 약속 시간 기준 각 참가자의 현재 위치에서 대중교통/도보 소요 시간을 계산하여 "지금 출발해야 합니다!" Push 알림 발송.
3. **🛡️ 모임 후 안심 귀가 모드**:
   - 모임 해산 후 집까지 무사히 들어가는지 선택적으로 1시간 동안 위치를 공유하는 안심 귀가 서비스.
4. **📸 도착 인증샷 & 핀 모음집 (Memory Pin)**:
   - 도착 후 찍은 사진을 해당 Pin에 기록하여 지난 약속 캘린더/추억 앨범으로 저장.

## 6. 비기능적 요구사항 (Non-Functional Requirements)

1. **배터리 최적화**:
   - `FusedLocationProviderClient`의 PRIORITY_BALANCED_POWER_ACCURACY 및 이동 거리 기반 업데이트 주기 조절로 배터리 소모 최소화.
2. **개인정보 및 보안 (Privacy First)**:
   - 위치 데이터는 모임이 진행 중인 동안만 수신 및 메모리/임시 서버에 유지하며, 약속 종료 후 서버 DB의 실시간 좌표 기록 즉시 파기.
3. **네트워크 효율성**:
   - WebSockets 또는 Firebase Realtime Database를 사용하여 3~5초 간격 또는 10m 이동 시에만 Delta 좌표 전송.
4. **권한 처리 (Permissions)**:
   - Android 10(API 29) 이상의 백그라운드 위치 권한(`ACCESS_BACKGROUND_LOCATION`) 및 알림 권한(`POST_NOTIFICATIONS`)에 대한 사용자 가이드 UX 제공.

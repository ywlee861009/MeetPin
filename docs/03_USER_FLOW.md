# 📱 03. User Flow & Screen Design (사용자 흐름 및 화면 설계서)

> **⚠️ 구현 현황 — 「단일 기기 데모 / 백엔드 미구현」 단계 (2026-08-01 기준)**
> 화면 플로우(핀 생성 → 초대 → 대기실 → 트래킹 → 도착)는 단일 기기에서 데모로 동작합니다. 다만 **여러 기기가 참여하는 실제 실시간 공유는 백엔드 미구현으로 불가**하며, 다른 참가자의 승낙·위치·도착은 데모 시뮬레이션으로 재현됩니다. 또한 Google Places 검색, 카카오톡 공유 등 일부 외부 연동은 아직 미구현일 수 있으니 각 화면 명세는 목표 UX로 참고하시기 바랍니다.

## 1. 전체 사용자 여정 (User Journey Overview)

```
[1. 메인 / 장소 검색] ──> [2. 핀 찍기 & 약속 설정] ──> [3. 딥링크 초대 공유]
                                                               │
┌──────────────────────────────────────────────────────────────┘
│
▼
[4. 대기실 (Lobby)] ──(전원 승낙 시)──> [5. 라이브 지도 (Live Tracking)] ──> [6. 도착 & 종료]
    │                                              │
    └─(거절/미승낙 시)─> [승낙 대기 유지]           └─(사생활 보호 알림 노출)
```

---

## 2. 화면별 세부 인터랙션 및 UX 명세

### 2.1 메인 & 약속 핀 작성 화면 (`CreatePinScreen`)
- **UI 구성**:
  - 화면 상단: 장소 검색창 (Google Places API 연동).
  - 화면 중앙: Google Maps 뷰 (기본값: 현재 내 위치).
  - 화면 하단: 핀 설정 드래그 시트 (Bottom Sheet).
- **사용자 동작**:
  1. 검색창에 장소 입력(예: "강남역 11번 출구") 또는 지도 직접 클릭하여 핀 드롭.
  2. 모임 이름 (예: "금요일 불금 모임"), 약속 날짜 및 시간 입력.
  3. "약속 핀 생성하기" 버튼 터치.

### 2.2 딥링크 생성 및 공유 화면 (`InviteShareScreen`)
- **UI 구성**:
  - 생성 완료 카드: 선택한 장소명, 약속 시간, 주선자 프로필.
  - 초대 링크 박스: `https://meetpin.app/invite/{groupId}` (클립보드 복사 버튼).
  - 빠르게 공유하기 버튼: 카카오톡 공유, SMS 메시지, 링크 복사.
- **사용자 동작**:
  - "카카오톡으로 초대 보내기" 버튼 클릭 ➔ 친구들에게 초대 딥링크 전송.
  - "대기실로 이동" 클릭.

### 2.3 초대 수락 및 대기실 화면 (`LobbyScreen`)
- **UI 구성**:
  - 약속 정보 요약 카드 (장소, 시간).
  - 참가자 목록 및 상태 칩:
    - 👑 **주선자**: 승낙 완료 (Accept)
    - 👤 **친구 A**: 🟢 **승낙 (Accepted)**
    - 👤 **친구 B**: 🟡 **대기 중 (Waiting)**
    - 👤 **친구 C**: 🔴 **거절 (Declined)**
  - 대기 안내 메시지: `"모든 참가자가 승낙해야 실시간 위치 공유가 시작됩니다! (2/3 수락 완료)"`
  - 수신자 View: "승낙하기", "거절하기" 액션 버튼.
- **트리거 로직**:
  - 마지막 대기자가 "승낙하기"를 누르는 즉시 화면 전환 카운트다운(3, 2, 1) 발생 ➔ `LiveTrackingScreen`으로 자동 이동.

### 2.4 라이브 지도 및 위치 공유 화면 (`LiveTrackingScreen`)
- **UI 구성**:
  - **전체 화면 Google Map**:
    - 📌 약속 장소 목적지 커스텀 핀 렌더링.
    - 🏃‍♂️ 참가자별 프로필 아바타가 표시된 실시간 렌더링 마커 (위치 이동 시 부드러운 보간 애니메이션).
    - 📏 목적지까지의 직선/경로 라인 및 ETA (예상 소요 시간), 남은 거리 표시.
  - **하단 메인 상태 바**:
    - 참가자 리스트 탭 (클릭 시 해당 참가자 위치로 카메라 이동).
    - "내 위치 공유 끄기 / 모임 종료" 긴급 버튼.
  - **상단 상태 바**:
    - 🟢 `"전원 승낙 완료! 라이브 공유 중"` 인디케이터.
- **주요 기능**:
  - **카메라 오토 포커스 (Fit Bounds)**: 모든 참가자의 위치와 약속 핀이 한 화면에 들어오도록 카메라 자동 조절 옵션.
  - **도착 핑 (Arrival Ping)**: 특정 참가자가 약속 장소 반경 50m 이내에 진입 시 축하 이펙트(폭죽 애니메이션) 및 알림 팝업.

### 2.5 도착 완료 및 모임 종료 화면 (`CompletionScreen`)
- **UI 구성**:
  - "모두 약속 장소에 무사히 도착했습니다! 🎉"
  - 약속 소요 시간 통계 요약 (예: "가장 먼저 도착: 친구 A (10분 전)").
  - "위치 공유가 완전히 종료되었습니다." 보안 안내 문구.
  - 메인 화면으로 돌아가기 버튼.

## 3. 예외 처리 & 엣지 케이스 (Edge Cases)

1. **위치 권한 거부 시**:
   - 위치 권한(`ACCESS_FINE_LOCATION`, `ACCESS_BACKGROUND_LOCATION`) 미허용 시 승낙 불가 안내 및 권한 설정 이동 다이얼로그 표시.
2. **네트워크 끊김 / GPS 불통**:
   - 특정 참가자의 위치가 1분 이상 업데이트되지 않을 경우 마커 반투명 처리 및 `"위치 신호 약함"` 상태 표시.
3. **참가자 중 도중 이탈 (초대 거절/약속 취소)**:
   - 한 사람이라도 초대 거절 시, 주선자에게 알림 팝업 전송 ➔ 미참가자를 제외하고 약속을 진행할지 재확인.

# 📍 MeetPin 프로젝트 문서 (Documentation)

> **⚠️ 구현 현황 — 현재 「단일 기기 데모 / 백엔드 미구현」 단계입니다 (2026-08-01 기준)**
>
> 이 폴더의 문서들은 **목표 스펙(To-Be)**입니다. 현재 코드는 다음과 같은 갭이 있습니다.
> - **백엔드·실시간 서버 미구현**: `:core:network` 모듈은 비어 있고, 데이터는 인메모리 `FakeMeetPinRepository`로만 동작합니다(앱 종료 시 소실, 네트워크 통신 없음).
> - **기기 간 실시간 위치 공유 불가**: 친구의 위치·이동·도착은 모두 단일 기기 내 데모 시뮬레이션입니다.
> - 반면 **아키텍처·UI·화면 플로우(핀 생성 → 초대 → 대기실 → 트래킹 → 도착)는 데모로 동작**하며 전 모듈 컴파일이 통과합니다.

MeetPin은 구글 지도를 기반으로 모임 장소를 핀으로 지정하고, 초대된 참가자들이 모두 승낙하면 약속 장소에 도착할 때까지 실시간으로 위치를 공유하는 Android 애플리케이션입니다.
